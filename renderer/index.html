Wallpaper

needs one tap on the tablet

Android gives adb no way to set the wallpaper outright, so this copies the image to the tablet and opens its "Set as" chooser with the picture already loaded. Tap Set as wallpaper, then pick Home screen.

System update

-

Firmware updates are signed and vendor-driven, so they cannot be applied over adb. This opens the update screen on the tablet so you can tap Download and install without hunting through Settings.

Power

asks first

A reboot is what settles the changes Apply makes, and an audit on a freshly rebooted tablet is the only one worth trusting. The tablet drops off USB for about a minute and comes back on its own. Powering off is one-way: nothing here can switch it back on, so someone has to press the button on the tablet.
