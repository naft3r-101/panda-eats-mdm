# Hard guard list - these are NEVER disabled, even if a bloat profile names them.
#
# This list is the difference between a debloat tool and a brick. Disabling the
# keyboard, the launcher, WebView, or the permission controller leaves a tablet
# that boots to a black screen or cannot be typed into, and fixing that on a
# device already sitting on a restaurant counter is a drive across town.
#
# On top of this static list, provision.js also protects, at runtime:
#   - the device's current IME       (settings get secure default_input_method)
#   - the device's current launcher  (cmd package resolve-activity HOME)
#   - every com.pandaeats.* package
# Those are resolved per device, because they differ between Samsung and Lenovo.

# --- Crashes the device ------------------------------------------------------
# The Google app / Assistant. This is NOT here to preserve a feature - it is
# here because `pm disable-user` on it takes system_server down and the tablet
# restarts itself. Verified on Tanya's SM-T510 (R52N10RAJ5D) on August 12, 2026:
# adb returned "Failure calling service package: Broken pipe (32)" on this exact
# package, and every command after it got "Can't find service: package".
#
# On One UI this package backs the launcher search widget and the assistant, and
# pulling it out from under a live SystemUI takes the whole box with it. It was
# an aggressive-tier entry in bloat/common.txt until then, so any run with
# Aggressive on hit it and rebooted the tablet.
#
# If you ever want this off, do it from Settings on the device, not over adb.
com.google.android.googlequicksearchbox
