# Bloat candidates present on most Android builds regardless of OEM.
#
# Format:  one package per line.
#          a leading "!" marks the entry as AGGRESSIVE tier - skipped unless the
#          Aggressive toggle is on.
#
# Nothing here is uninstalled. Everything is `pm disable-user --user 0`, which is
# reversible with `pm enable` and survives nothing worse than a reboot. Packages
# that are not present on the device are skipped silently, so an over-broad list
# is safe - the Audit view shows you exactly which ones were actually found
# before anything is touched.
#
# Deliberately NOT here, per the "tablet stays general-purpose" decision:
# Chrome, Play Store, Gmail, Files, Calculator, Clock, Camera, Settings.
